# jackrz412.github.io

My personal portfolio, showcasing my personal data analysis and AI engineering projects, along with some other side quests I'd like to share with the world. 

Live site: https://jackrz412.github.io/

## Built with

- [Astro](https://astro.build/), a static site generator
- GitHub Actions, which builds the site and deploys it to GitHub Pages on every push to `main`

## Run it locally

Requires Node.js 22.12 or newer.

```sh
npm install       # install dependencies
npm run dev       # local preview at http://localhost:4321
npm run build     # build the site into dist/
npm run preview   # serve the built site locally
```
